# Changelog

## 1.1.0
- Penambahan fitur Runner bawaan VS Code (tombol Play ▶️ di pojok kanan atas editor).
- Eksekusi berkas aktif melalui menu konteks dan pintasan keyboard `Ctrl + F5`.
- Eksekusi kode terseleksi via `Shift + F5`.
- Perintah pembuka terminal interaktif REPL Luai (`Luai: Buka Terminal Interaktif REPL`).
- Penyertaan binary interpreter Luai bawaan (`bin/luai.exe`) di dalam paket ekstensi sehingga pengguna tidak perlu mendownload atau menyetel Environment Variable PATH manual.
- Konfigurasi kustom `luai.executablePath` dan `luai.clearTerminalBeforeRun`.

## 1.0.0
- Rilis perdana ekstensi VS Code untuk bahasa pemrograman Luai.
- Dukungan TextMate Grammar untuk sintaks Bahasa Indonesia Luai.
- Konfigurasi bahasa lengkap (bracket matching, auto-closing, folding, indentation).
- Kumpulan snippets untuk struktur sintaks Luai.
